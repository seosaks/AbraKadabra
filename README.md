# АбраКадабра

Исправляет текст, набранный в другой раскладке, и переключает язык дальнейшего ввода. Наберите `Ghbdtn rfr ltkf` и нажмите **Ctrl+Esc** — получится «Привет как дела». Сочетание работает в обе стороны.

**[Скачать для macOS · 1.0.0-beta.1 · ZIP](https://github.com/seosaks/AbraKadabra/releases/download/v1.0.0-beta.1/AbraKadabra-1.0.0-beta.1-macOS-universal.zip)** · [Страница выпуска и контрольная сумма](https://github.com/seosaks/AbraKadabra/releases/tag/v1.0.0-beta.1)

В одном архиве есть версии для Apple Silicon и Intel. Для работы нужны macOS 13 Ventura или новее и включённые русская и английская раскладки.

### Первый запуск

1. Распакуйте ZIP, перенесите «АбраКадабру» в папку «Программы» и откройте её оттуда.
2. Это предварительный выпуск с локальной подписью. У него пока нет сертификата Developer ID и нотариального заверения Apple. При открытии скачанной копии Gatekeeper может показать предупреждение. Если вы доверяете этому выпуску, следуйте официальной инструкции для конкретного приложения. [Как macOS проверяет приложения](https://support.apple.com/ru-ru/102445)
3. По запросу macOS разрешите «АбраКадабре» управлять вводом в настройках конфиденциальности. Это нужно для глобального сочетания и замены текста в другом приложении. В зависимости от версии macOS раздел называется «Универсальный доступ» или «Управление устройством и доступ к данным».
4. Откройте TextEdit, введите `Ghbdtn` в английской раскладке и нажмите **Ctrl+Esc**. Слово должно стать «Привет», а следующий ввод — русским.

### Что именно исправится

- **Есть выделение** — изменится выделенный фрагмент.
- **Только что набрали фразу** — изменится серия ввода перед курсором. Щелчок мышью, перемещение курсора, смена поля или раскладки, новая строка и пауза дольше 20 секунд завершают серию.
- **Серия завершена** — приложение попробует исправить последнее слово перед курсором.

Нажмите розовую иконку **АФ** в строке меню, чтобы выбрать один из пяти звуков, включить или выключить звуковой сигнал либо изменить запуск при входе. При ошибке в этом же меню появится пояснение.

### Совместимость и обработка текста

Для обеих архитектур минимальная версия сборки — **macOS 13.0**. В распакованном архиве на Mac с Apple Silicon под macOS 27.2 проверены преобразование русской и английской раскладок и границы серии ввода. Проверка arm64 выполнена напрямую, x86_64 — через Rosetta. Работа на физическом Intel Mac и непосредственно на Ventura требует отдельной проверки.

В обычных текстовых полях утилита использует системный интерфейс универсального доступа. В Яндекс Браузере и приложениях чата OpenAI она использует выделение, копирование и вставку. Совместимость зависит от редактора. Если поле не поддерживает замену, откройте меню программы и посмотрите сообщение.

Преобразование выполняется локально. Для определения серии программа считает нажатия. На время замены в веб-полях она использует системный буфер обмена и восстанавливает его содержимое, если за это время буфер не изменился.

### Сборка из исходников

На Mac с Xcode или его инструментами командной строки выполните из корня проекта:

```sh
./build.sh
```

Результат — универсальное приложение `АбраКадабра.app` в папке проекта. Чтобы запустить встроенную проверку, включите обе раскладки и выполните:

```sh
./АбраКадабра.app/Contents/MacOS/AbraKadabra --check
```

Внешние библиотеки для сборки не требуются.
